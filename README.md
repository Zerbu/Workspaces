# Workspaces
Workspaces is a plugin for Godot that allows you to create an quickly swap between different Workspaces, similar to the feature in Blender.
You can assign layouts to Workspaces, configure it so that a file is folder is automatically selected in the FileSystem dock, and even hide parts of the editor that aren't relevant to what you're working on!
There's also an experimental file filter feature that lets you to restrict which folders an extensions are shown in the FileSystem dock for that Workspace. Just be warned that it's quite hacky.
